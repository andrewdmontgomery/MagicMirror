# AQI View Implementation Plan

**Goal:** third `aqi` mode on MMM-WeatherMap — a static, full-bleed CAMS US-AQI wash in standard EPA colors with a circular home badge, no timeline, and a threshold-driven default view. Scope A only: current field, no history, no forecast loop.

**Why this shape:** WAQI tiles are station pins (verified live over MN: numbered markers, no field to interpolate). The wash in Apple Weather is a model field, so we sample the model instead — CAMS global (~0.4°) via Open-Meteo's keyless multi-location API. Verified live: 315-point 1° grid over the Midwest renders green→yellow; Texas grid hits 105 (orange) with DFW ~93, matching Apple. At the mirror's default (420 px, zoom 7 ≈ 364 km wide) CAMS cells render ~51 px — smooth blobs, no metro structure. City-scale detail (HRRR smoke 3 km or station fusion) is a later phase, not this one.

**Architecture:** `node_helper.js` fetches a regional 15×21 grid plus a continental North-America grid per refresh and replies `AQI_FIELDS_RESULT` with both fields plus the bilinear home value. The frontend paints EPA-colored canvases to two stacked MapLibre `ImageSource`s (same technique as the `/tmp/aqi-wash-preview.html` prototype: bilinear upscale, feathered edges, 0.8 opacity). MMM-WeatherWatcher gains a three-way default: AQI ≥ threshold → `'aqi'`, else rain → `'precip'`, else `'wind'`.

**Tech Stack:** Open-Meteo air-quality API (keyless, already a project dependency in spirit) + existing socket/MapLibre patterns. No new dependencies, no Dockerfile change, no `config.js` change (defaults carry the feature).

---

## Decisions

1. **Static field, no timeline** — CAMS updates every 12 h; hourly air barely moves. Timeline overlay is hidden in AQI mode; the scaffolding stays for a future forecast loop.
2. **Fixed home-centered window** (±7° lat / ±10° lon) — no pan-refetch. Covers plausible pans at zoom ≥ 6; edges feathered so over-pan degrades gracefully.
3. **AQI outranks rain in the default rule** — AQI ≥ 101 is rare and health-relevant; rain is the common case. Threshold configurable (`aqiThreshold`, default 101).
4. **Badge reuses the wind callout chrome** (circle + tail pinned to home) with AQI content: big number, "AQI", ring stroked in the value's EPA color.
5. **Null policy** — model values can be null: transparent pixels in the wash, nearest-non-null (else em-dash) for the badge.
